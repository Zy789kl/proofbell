# 填写课程蓝图

先选一门课的两三个目标，每个目标用一句可观察的行为描述。给每道题和练习分配稳定编号。改版时保留仍指向同一目标或题目的编号。

支持 JSON Schema 的编辑器可关联 [蓝图模式](blueprint.schema.json)，在编辑时检查字段类型、范围和必填项。在蓝图顶层添加 `"$schema": "./blueprint.schema.json"` 即可关联同目录的模式文件。目标和题目编号是否重复、关联是否有效、分值是否超出题目预算及教学时序仍由 Proofbell 审计。

| 字段 | 填写方法 |
| --- | --- |
| `schema` | 填整数 `1` |
| `course` / `title` | 课程编号与名称，同一课程的两次修订共用编号 |
| `objectives[]` | 每个目标填 `id`、`title`、`level`、`minimum_points` 和布尔值 `require_rehearsal` |
| `evidence[]` | 每项填 `id`、`title`、`phase`、`kind`、`points` 和 `links` |
| `links[]` | 每项关联填 `objective`、实际要求的 `level`、分配的 `points`，以及可复核的评分细则或练习产出 `criterion` |

编号使用小写英文字母、数字、连字符或下划线。阶段可用周次，也可按活动顺序编号。要求练习的目标须在首次达标考核**之前**出现达到同等或更高要求的练习。同一阶段无法证明先后。

等级由课程团队预先约定。示例使用四级口径：L1 识别或回忆，L2 解释，L3 应用或核验，L4 根据证据作出判断并为决定辩护。等级按证据关联填写，一道综合题针对不同目标可能要求不同表现。

练习使用 `practice`，本身及关联均为零分。考核使用 `assessment`，题目分值为 1–1000 的整数。多个目标按评分细则拆分同一道题的分值，单题各关联的分值总和不得超过该题分值。分值小于题面总分时，剩余分值会单独列出。需要半分时，可先统一把所有题目分值和阈值乘以二。

目标须达到最低达标考核分值，并满足自己的练习条件。课程通过还要求没有未归属考核分值。孤立的零分练习会列出供复核。报告中的等级与分值依赖输入标注，阅读实际题目和评分细则仍是审阅的一部分。

输入为 UTF-8 JSON。目标与证据分别最多 200 和 1000 项。所有表格字段均须提供，附加字段留作元数据。项目样例只含课程设计，无学生档案或作答记录。
